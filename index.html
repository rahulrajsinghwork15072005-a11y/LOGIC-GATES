01 — CORE IDEA

〈 HOW IT WORKS 〉

Graph = Map of nodes + array of edges. Simulate by fixed-point iteration until stable — or flag oscillation.

CONCEPT 01
🔁

Fixed-Point Propagation

Reset non-source gates to false. Repeatedly evalComp(c) for every node. If any output flips, loop again. Stop when a full pass makes zero changes — the circuit has settled.

propagate() · O(n×iter)
CONCEPT 02
⚠

Oscillator / Feedback

If it never settles within 6·n+20 passes, it's an oscillator (e.g. NOT loop, illegal SR latch). Flag oscDetected and show warning instead of hanging.

feedback · real hardware failure
CONCEPT 03
🕸

Graph Model

components: Map(id→comp) are nodes; wires: {from:{id,port}, to:{id,port}} are edges. getInput(id,port) follows the wire back to its source's .state.

Map + array · getInput
CONCEPT 04
📐

World ↔ Screen

worldToScreen / screenToWorld apply zoom, panX, panY. snap(16) quantises placement. Two stacked canvases (components + wires) keep redraws cheap.

pan/zoom · dual-canvas
CONCEPT 05
🔢

7-Segment Decoder

Read 7 input bits, pack into an integer via bit shifts (bits.reduce(|)), look up SEG_PATTERNS (maps digits 0-9 to segment on/off).

bitmask · hardware decoder
CONCEPT 06
⏱

Clocks & Sequential

Clock toggles .state on interval 1000/Hz/2 ms. Each tick triggers propagate() so downstream gates — including feedback latches — update like real sequential logic.

clockHz · setInterval

⧩ ARCHITECTURE ⧩

Single-file 762-line prototype refactored to modular UMD + Worker + Viz + library + tests — same pattern as Compiler Forge.

File-by-File (mirrors Compiler Forge README)

logic-engine.js — Single source of truth for simulation. Exports CDEFS catalogue, evalComp truth tables (AND→every, OR→some, NOT→!, NAND/NOR negations, XOR→!==, XNOR→===, BUF), getInput (finds wire by to.id/port and returns source state), getPortPos (out on right, ins distributed down left), propagate (reset non-sources → loop recompute until stable or MAX=n*6+20 → oscillator), clock helpers, 7-seg decoder, setOf/addAll, UMD wrapper.
logic-worker.js — Offloads heavy propagation. importScripts('logic-engine.js') with try/catch fallback. onmessage handles propagate/tick/eval/ping; serialises Map→Array for postMessage; timeout fallback to main thread.
viz.js — XSS-safe SVG. esc() escapes HTML. buildGateSVG draws gate body+symbol+ports, buildWireSVG draws bezier with glow for HIGH, buildSeg7SVG draws 7 bars, buildCircuitSVG composes full circuit snapshot for export.
logic-library.js — Declarative circuits. Each entry has name, description, comps[], wires[] plus build(ctx) that calls createComp/addWire. Helpers get/list/injectExample/instantiate mirror grammar-library.js.
app-integration.js — Bridges UI↔engine↔worker. initWorker creates Worker if not file:, wires onmessage to promise map, simulateInWorker with 2.5s timeout fallback, propagateAsync patches UI states back, loadExampleAsync via LogicLibrary + LogicEngine.
script.js — The lab. Dual canvases, grid dots, snap(16), pan/zoom, port hit-testing (Math.hypot), drag, pendingWire bezier, clock interval, prop panel, sim log (cap 50), save/load localStorage + JSON/SVG export, keyboard (1/A/O/N/L/W/S/Del/Esc), START overlay, Y2K chrome (glitter, bgCanvas, ticker, dark toggle). Uses LogicEngine if present, inline fallback otherwise.
index.html / style.css / lab.css — Y2K maximalist shell (glitterCanvas, bgCanvas, ticker, cyber-nav, hero with terminal typewriter, token-strip, section-containers, lab flex layout). style.css (from Compiler Forge) holds theme; lab.css holds simulator layout (left-panel, canvas-wrap, comp-btn, osc-warn, tip).
tests/ — Node assert proofs: logic-engine.test.js checks UMD, CDEFS, setOf/addAll, snap, port positions, truth tables exhaustive, getInput, propagation (switch→LED, gate chains, feedback SR latch stable, NOT-loop oscillator), 7-seg, clock; viz.test.js checks XSS-safe esc and SVG builders.

Interview Guide (like Compiler Forge)

30-sec pitch: “Logic Forge is a digital-circuit simulator. You place gates on an infinite pan/zoom canvas, wire ports, and a propagation engine settles signals by repeatedly evaluating every gate until stable — fixed-point iteration with a safety cap. If it never settles I flag an oscillator, which is exactly how real hardware fails.”

Q: How do you simulate? A: Graph of Map nodes + Array edges. Reset non-sources to false, then loop evalComp for each node until a full sweep makes no change. Handles ripple without topological sort; detects feedback via iteration cap.
Q: Feedback? A: Cap ≈ 6·n+20. If still flipping at cap → oscDetected. Example: NOT output→input never settles; SR NOR latch wired illegally oscillates.
Q: Why two canvases? A: Wires change every propagate (glow on HIGH), components rarely move; separate layers avoid repainting everything.
Q: Scale to thousands of gates? A: Current is O(n·iter) fine for hundreds. At scale switch to event-driven work queue (only re-evaluate gates whose inputs changed) — like Verilog simulators.
Q: Clock? A: Source toggles on setInterval(1000/Hz/2); each toggle calls propagate() so downstream sequential logic updates.
Q: UMD/Worker? A: Every engine module uses (function(root,factory){...}) wrapper so it works as window.LogicEngine, self.LogicEngine in Worker via importScripts, and require() in Node for tests.
